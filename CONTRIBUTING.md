# Contributions and evidence safety

This repository is a documented educational lab. Contributions are welcome for clearer reasoning, security recommendations and test plans, but **do not** add invented implementation claims or unsanitized screenshots.

Before submitting a change:

1. Separate **observed results**, **assumptions**, and **proposed work**.
2. Keep a test-to-evidence mapping in `tests/validation-matrix.md`.
3. Redact tenant/account identifiers and any personal or authentication details.
4. Never commit credentials, tokens, recovery material, application secrets or private tenant exports.
5. Avoid claims of production deployment or compliance certification.
